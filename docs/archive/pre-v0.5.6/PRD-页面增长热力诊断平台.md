## 1. 文档摘要

### 1.1 一句话定义

热力增长诊断台是一套面向产品经理、运营和增长团队的内部分析工具。它将神策导出的页面元素点击数据、页面截图和热力图截图统一到同一页面画布上，自动发现点击分布、趋势、异常和页面结构问题，输出带证据、置信度与验证方案的页面优化建议。

### 1.2 本期要解决的问题

目前团队可以在神策中查看页面热力图，也可以获得页面按钮元素的日点击数，但存在以下问题：

1. 数据与页面视觉结构分离，需要人工在表格、官网和热力图之间反复对照。
2. 神策热力图无法导出结构化数据，只能截图，历史对比和协作不方便。
3. 点击量本身容易被误读。高点击可能来自高流量、重复点击或误触，低点击也可能是元素曝光不足。
4. 分析依赖个人经验，结论缺少统一口径、证据、优先级和验证方法。
5. 页面改版前后的数据、分析结论和实验结果没有形成可复用的闭环。

### 1.3 MVP 交付结果

用户完成一次分析后，应得到：

- 一张可交互的页面点击分布图；
- 页面、日期、元素维度的核心指标和趋势；
- 自动识别的问题清单；
- 每个问题对应的证据、影响范围、置信度和优化假设；
- 可供产品和运营评审的分析报告；
- 可跟踪的优化任务与改版前后对比基线。

### 1.4 最重要的分析边界

仅有“元素日点击次数”时，系统只能可靠描述点击的数量、分布和变化，不能直接计算真实点击率、转化率或留存率，也不能证明某个页面元素造成了业务结果变化。

因此系统必须按照数据完备度区分结论层级：

| 数据层级 | 已接入数据 | 可以输出 | 不得输出 |
|---|---|---|---|
| L1 点击观察 | 元素、日期、点击次数 | 点击份额、趋势、集中度、异常、优化假设 | 真实 CTR、转化提升、留存提升、因果结论 |
| L2 页面效率 | L1 + 页面 PV/UV，最好含元素曝光 | 页面点击效率、元素点击率、首屏效率 | 未接入转化事件时的转化结论 |
| L3 转化诊断 | L2 + 目标转化事件/漏斗 | 转化率、漏斗流失、元素点击后的转化表现 | 未经实验验证的因果结论 |
| L4 留存验证 | L3 + 用户标识与回访/留存事件 | 分群留存、点击行为与留存相关性 | 将相关性表述为因果性 |

所有报告必须显示当前数据层级。低层级数据生成的建议必须使用“观察”“可能”“建议验证”等措辞。

## 2. 产品背景

### 2.1 业务背景

公司官网已私有化部署神策数据。当前可获取三个活动页面的 Web 元素点击数据，数据粒度为“某页面上某按钮元素的日点击次数”；同时可以在神策查看点击热力图，但只能通过截图留存。

产品经理和运营希望根据这些数据识别页面问题，形成优化方案，以提高用户从看到页面、发生点击、完成转化到后续留存的可能性。增长负责人希望这一过程标准化、可重复、可审计，而不是仅依赖分析人员的截图解读。

### 2.2 当前工作流程

1. 分析人员进入神策查看指定页面和日期范围。
2. 手动导出或整理元素点击数据。
3. 截取神策热力图。
4. 对照线上页面，凭经验寻找热点、冷点和异常。
5. 在文档或群聊中描述优化建议。
6. 产品和运营自行决定是否改版，改版结果缺少统一回看。

### 2.3 当前流程痛点

| 痛点 | 具体表现 | 业务影响 |
|---|---|---|
| 数据割裂 | 点击表、页面截图和热力图不在同一视图 | 分析耗时、容易错配元素 |
| 口径不统一 | 有人看总点击，有人看占比，有人凭颜色判断 | 结论不可比较 |
| 缺少分母 | 只有点击次数，没有 PV/UV 或曝光 | 容易把流量变化误判为页面效果变化 |
| 截图不可计算 | 热力图仅是视觉证据 | 无法直接聚合、排序或做趋势分析 |
| 建议缺少证据链 | 建议和数据之间关系不清晰 | 评审难、执行优先级混乱 |
| 无验证闭环 | 改版前后基线和结果散落 | 无法积累页面优化知识 |

### 2.4 产品机会

将结构化点击数据作为主要计算来源，将页面截图和热力图截图作为空间定位及视觉佐证，通过规则诊断、统计分析和标准化报告建立“数据导入 - 发现问题 - 提出假设 - 制定实验 - 复盘结果”的闭环。

## 3. 产品目标与非目标

### 3.1 业务目标

1. 将单页一次常规点击分析的人工处理时间降低 60% 以上。
2. 让 100% 的优化建议具备可追溯的数据证据、分析口径和验证方法。
3. 让产品、运营和增长团队使用同一套指标和问题优先级进行页面评审。
4. 建立三个页面持续可比的历史基线，为后续转化和留存分析做好数据结构准备。

### 3.2 用户目标

- 分析人员：快速完成数据整理、元素映射、问题发现和报告制作。
- 产品经理：明确页面哪里有问题、影响多大、优先改什么以及如何验收。
- 运营人员：理解文案、活动入口和内容区块的用户响应，形成可执行调整方案。
- 增长负责人：查看跨页面问题、优化机会、改版进度和业务结果。

### 3.3 产品成功指标

#### 使用效率指标

- 单页首次分析完成时长：目标小于 20 分钟，不含神策数据准备时间；
- 数据重复导入成功率：大于 98%；
- 元素自动或手动映射完成率：大于 95%；
- 报告导出成功率：大于 99%。

#### 分析质量指标

- 建议具备数据证据比例：100%；
- 建议具备验证方案比例：100%；
- 人工抽检的元素映射准确率：大于 95%；
- 系统将“点击量”误标为“点击率”的次数：0；
- 无足够数据却输出确定性转化/留存结论的次数：0。

#### 长期业务指标

以下指标只有接入相应分母与结果事件后才能作为产品效果指标：

- 页面主 CTA 点击率；
- 目标转化率；
- 漏斗各步骤流失率；
- 新用户次日、7 日或业务定义周期的留存率；
- 已验证优化建议的正向实验比例。

### 3.4 非目标

MVP 不包含：

1. 替代神策完成埋点采集、用户画像或全站行为分析；
2. 仅依据截图颜色反推精确点击次数；
3. 自动修改或发布公司官网；
4. 自动执行 A/B 分流；
5. 在没有转化或留存数据的情况下承诺业务指标提升；
6. 通过生成式模型无依据地给出页面设计结论；
7. 支持三个已知活动页面之外的大规模全站爬取。

## 4. 用户与使用场景

### 4.1 用户角色

| 角色 | 核心任务 | 默认权限 |
|---|---|---|
| 分析管理员 | 配置页面、导入数据、校验元素、生成诊断 | 查看、编辑、导入、发布报告 |
| 产品经理 | 查看诊断、筛选问题、创建优化方案、填写结果 | 查看、评论、创建任务、提交复盘 |
| 运营人员 | 查看内容和 CTA 表现、提出文案或活动调整 | 查看、评论、创建任务 |
| 增长负责人 | 查看总览、审批优先级、跟踪结果 | 查看全部、审批、导出 |
| 系统管理员 | 用户、权限、字典、数据源和审计配置 | 系统配置 |

### 4.2 核心场景

#### 场景 A：日常页面巡检

分析人员导入昨日或近 7 日数据，系统自动与历史基线比较，标记点击异常、热点迁移和主 CTA 变化，形成日常巡检摘要。

#### 场景 B：活动中期优化

运营查看活动页面的点击分布，发现用户大量点击次要入口而主 CTA 点击份额较低。系统给出证据、可能原因和待验证假设，运营创建文案或布局调整任务。

#### 场景 C：页面改版评审

产品经理在改版前查看基线报告，选定目标指标和护栏指标；改版上线后选择对比时间段，系统输出前后变化，同时提示流量结构、星期效应和数据缺失等风险。

#### 场景 D：管理层周报

增长负责人查看三个页面的诊断总览，包括新增问题、待处理高优先级建议、改版进度和已验证结果，并导出评审报告。

## 5. 产品原则

1. **数据先于判断**：没有证据的建议不进入正式报告。
2. **口径显式可见**：指标名称、公式、时间范围、分母和数据完整度随时可查。
3. **观察与因果分离**：前后对比是相关性证据，A/B 或严格准实验才用于因果判断。
4. **截图用于定位，结构化数据用于计算**：热力图截图不能作为精确数值来源。
5. **建议必须可验证**：每条建议包含预期影响指标、护栏指标和验证方式。
6. **人机协作**：系统发现模式并生成候选解释，分析人员负责校验页面语境和发布结论。
7. **默认私有与最小化采集**：MVP 不需要保存可识别个人身份的信息。

## 8. 核心业务流程

### 8.1 首次分析流程

1. 分析管理员创建页面，填写页面名称、URL、业务目标和主 CTA。
2. 上传页面原始长截图，记录截图日期、视口宽度和页面版本。
3. 上传神策热力图截图，可选填对应的日期、设备和神策筛选条件。
4. 上传点击数据文件，选择日期范围并完成字段映射。
5. 系统执行格式校验、重复校验、时间范围校验和总量校验。
6. 系统根据元素文本、选择器、链接和坐标生成元素映射建议。
7. 用户在画布中确认、移动、新建或合并元素区域。
8. 系统计算指标并生成候选问题。
9. 用户审核问题，补充业务背景，调整置信度或标记不适用。
10. 系统生成优化建议草稿和验证方案。
11. 用户发布报告，产品和运营创建优化任务。

### 8.2 重复数据更新流程

1. 选择页面和新日期范围；
2. 上传结构相同的数据文件；
3. 系统自动沿用字段及元素映射；
4. 对新增或失效元素发出待确认提醒；
5. 更新趋势、异常和报告草稿。

### 8.3 改版复盘流程

1. 在优化任务中定义基线区间、上线时间、目标指标和护栏指标；
2. 上传或同步上线后数据和新页面截图；
3. 系统识别页面版本变化并要求确认元素继承关系；
4. 选择同比或环比区间，展示绝对变化、相对变化和数据风险；
5. 当有 UV 或转化分母时计算相应比率及统计区间；
6. 用户记录结果：正向、负向、中性、无法判断；
7. 结论进入页面优化知识库。

## 9. 数据设计

### 9.1 MVP 必需输入

#### A. 页面配置

| 字段 | 必填 | 示例 | 说明 |
|---|---:|---|---|
| page_id | 是 | campaign_001 | 系统内唯一标识 |
| page_name | 是 | 暑期会员活动页 | 页面显示名称 |
| page_url | 是 | https://example.com/summer | 页面 URL，参数清洗规则可配置 |
| business_goal | 是 | 会员开通 | 页面主要业务目标 |
| primary_cta_ids | 是 | btn_buy_now | 一个或多个主 CTA |
| owner | 是 | 张三 | 页面负责人 |
| status | 是 | active | 活动中、已结束、归档 |

#### B. 元素日点击数据

MVP 推荐标准模板：

| 字段 | 必填 | 示例 | 说明 |
|---|---:|---|---|
| date | 是 | 2026-07-20 | 自然日，使用 Asia/Shanghai |
| page_url 或 page_id | 是 | campaign_001 | 用于归属页面 |
| element_id | 是 | btn_buy_now | 稳定元素标识；没有时由系统生成映射键 |
| element_name | 是 | 立即领取 | 对用户可读的名称 |
| click_count | 是 | 1260 | 当日点击事件次数 |
| element_text | 否 | 立即领取 | 页面可见文本 |
| element_selector | 否 | #hero .cta | CSS 选择器或神策元素路径 |
| target_url | 否 | /checkout | 点击后目标链接 |
| x/y 或 element_position | 否 | 420/680 | 若神策导出提供坐标则使用 |
| device_type | 否 | mobile | mobile/desktop/tablet |
| page_version | 否 | v3 | 页面版本 |

#### C. 截图

| 类型 | 必填 | 用途 | 约束 |
|---|---:|---|---|
| 原始页面截图 | 是 | 作为可交互画布和视觉上下文 | 推荐完整长截图、无浏览器边框、PNG/JPG |
| 神策热力图截图 | 否但推荐 | 辅助人工确认热点位置 | 必须记录筛选日期、设备、视口宽度 |

### 9.2 推荐增强输入

| 数据 | 推荐字段 | 解锁能力 |
|---|---|---|
| 页面流量 | date、page_id、PV、UV | 页面级点击效率、流量归一化 |
| 元素曝光 | date、element_id、impression_uv | 元素真实 CTR、折叠区曝光判断 |
| 点击用户 | click_uv | 降低重复点击干扰 |
| 转化事件 | user_id_hash、event_time、conversion_type | 点击后转化、漏斗分析 |
| 留存事件 | user_id_hash、cohort_date、return_date | 分群留存分析 |
| 渠道与设备 | source、campaign、device | 结构变化解释和分群诊断 |
| 页面发布记录 | version、publish_time | 准确划分改版前后区间 |

### 9.3 数据导入规则

1. 支持 CSV 和 XLSX，单文件不超过 50 MB。
2. 编码优先识别 UTF-8；无法识别时提示用户选择。
3. 日期统一转换为 Asia/Shanghai 自然日。
4. `click_count` 必须为非负整数；空值不自动视为 0。
5. 同一 `page_id + date + element_id + device_type + page_version` 视为唯一键。
6. 重复行默认聚合前必须提示用户；用户可选择求和、覆盖或取消。
7. 元素名称变化但稳定 ID 相同时保留历史别名。
8. 页面 URL 默认去除 `utm_*` 等营销参数，保留业务参数的规则由管理员配置。
9. 数据导入必须保留源文件、导入人、时间、字段映射和校验结果。

### 9.4 截图与元素映射

#### 映射优先级

1. 页面截图采集时获得的 DOM 元素 ID 与边界框；
2. 稳定的 `element_id` 或 CSS 选择器；
3. 元素文本 + 目标 URL；
4. 点击坐标聚类；
5. 人工在截图上框选。

#### 映射状态

- 已自动匹配：高置信度且通过校验；
- 待确认：存在多个候选位置；
- 已人工确认：用户完成框选或校正；
- 未映射：有点击数据但画布上无位置；
- 已失效：历史元素在当前页面版本不存在；
- 已合并：多个数据标识属于同一视觉按钮；
- 组合元素：同一业务入口含图标、文字等多个可点击子元素。

#### 映射质量要求

- 发布正式报告前，主 CTA 必须全部完成映射；
- 有点击元素的映射覆盖率低于 90% 时显示红色数据质量提示；
- 未映射元素仍参与总量计算，但不可参与空间位置类诊断；
- 一个截图仅对应一个页面版本与一种视口；移动端和桌面端分别建图。

### 9.5 截图使用原则

神策热力图截图只能用于：

- 辅助确认点击集中区域；
- 留存神策界面中的原始视觉证据；
- 在报告中进行视觉对照。

系统不得仅根据热力颜色推算精确点击次数。若截图筛选条件与结构化数据的页面、日期或设备不一致，系统必须禁止叠加并提示原因。

### 9.6 数据质量评分

每次分析生成 0-100 分的数据质量分：

| 维度 | 权重 | 判断示例 |
|---|---:|---|
| 文件完整性 | 20 | 日期连续、关键字段非空 |
| 元素稳定性 | 20 | 稳定 ID 覆盖情况 |
| 映射覆盖率 | 20 | 已定位点击量占总点击量比例 |
| 截图一致性 | 15 | 页面版本、日期、设备一致 |
| 指标分母 | 15 | 是否提供 PV/UV、曝光 |
| 异常与重复 | 10 | 重复数据、突增突降、负值 |

数据质量分低于 60 时，系统允许查看但不允许发布正式结论；60-79 时报告标记“谨慎解读”；80 以上标记“数据质量良好”。管理员可强制发布，但必须填写原因并记录审计日志。

## 10. 指标体系

### 10.1 L1 点击观察指标

#### 元素点击次数

```text
Element Clicks = 所选时间范围内该元素 click_count 之和
```

说明：代表事件次数，不等于点击人数，也不等于点击率。

#### 元素点击份额

```text
Click Share = 元素点击次数 / 当前页面已纳入元素的总点击次数
```

用途：观察用户点击注意力在页面内的分配。若埋点仅覆盖部分按钮，必须显示“已埋点元素内份额”。

#### 主 CTA 点击份额

```text
Primary CTA Share = 所有主 CTA 点击次数 / 当前页面已纳入元素总点击次数
```

用途：判断已记录点击是否集中于页面核心任务，不等于主 CTA 点击率。

#### 点击集中度

MVP 同时展示 Top 3 点击份额和归一化 HHI：

```text
Top3 Share = 点击量最高三个元素点击次数 / 页面元素总点击次数
HHI = sum(每个元素点击份额 ^ 2)
```

用途：识别点击是否过度分散或集中。阈值需要结合页面类型，不以统一好坏判断。

#### 点击趋势

```text
日变化率 = (当日点击 - 前一日点击) / 前一日点击
7 日移动均值 = 最近 7 个有效自然日点击均值
```

当分母为 0 时不计算变化率，显示“由 0 增长至 N”。

#### 位置区块点击份额

```text
区块点击份额 = 区块内已映射元素点击次数 / 所有已映射元素点击次数
```

页面区块由用户标注为首屏、权益介绍、案例、FAQ、底部 CTA 等。没有元素曝光时，不将低点击解释为低效率。

### 10.2 L2 页面效率指标

接入页面 UV、PV 或元素曝光后启用：

```text
页面点击次数/PV = 页面内已记录点击次数 / 页面 PV
主 CTA 点击 UV 率 = 主 CTA click_uv / 页面 UV
元素 CTR = 元素 click_uv / 元素 impression_uv
重复点击系数 = 元素 click_count / 元素 click_uv
```

优先使用 UV 口径。若只有事件次数和 PV，指标命名必须写为“点击次数/PV”，不得简称 CTR。

### 10.3 L3 转化指标

```text
页面转化率 = 完成目标转化的去重用户数 / 页面访问 UV
点击后转化率 = 点击某元素后在归因窗口内转化的用户数 / 点击该元素的去重用户数
漏斗步骤转化率 = 下一步骤 UV / 当前步骤 UV
```

归因窗口、跨设备规则和转化去重规则必须在报告中可见。

### 10.4 L4 留存指标

```text
N 日留存率 = 首次访问或首次转化用户中，在第 N 日满足回访事件的用户数 / cohort 用户数
```

必须由业务先定义“留存事件”，例如再次访问、再次使用核心功能或再次付费。仅访问官网不一定代表有效留存。

### 10.5 指标通用展示规范

- 指标卡必须显示时间范围；
- 比率指标必须显示分子和分母；
- 变化值同时显示绝对变化和相对变化；
- 数据不完整时显示缺失，不使用 0 补齐；
- 低样本指标显示样本不足，不进入自动结论；
- 所有指标提供口径说明入口。

## 11. 功能需求

### 11.1 工作台总览

#### 目标

让增长负责人和分析人员快速理解三个页面当前状态。

#### 页面组成

1. 顶部筛选：日期范围、页面、设备、页面版本；
2. 数据层级和质量状态；
3. 页面概览表：总点击、主 CTA 份额、Top 3 份额、异常数、待处理建议；
4. 新增异常时间线；
5. 高优先级优化机会；
6. 优化任务状态；
7. 最近发布报告。

#### 交互规则

- 默认显示最近 7 个完整自然日；
- 页面之间点击量仅作规模对比，不默认判断页面好坏；
- 缺少共同指标时，不生成跨页面排行榜；
- 点击任一异常进入对应页面和元素详情。

### 11.2 数据导入

#### 步骤

1. 选择页面或新建页面；
2. 上传文件；
3. 预览前 20 行；
4. 进行字段映射；
5. 设置日期格式、设备和页面版本；
6. 查看校验结果；
7. 处理重复及冲突；
8. 确认入库。

#### 校验反馈

- 错误：必须修复才能继续，如日期无法解析、点击数为负；
- 警告：可继续但影响分析，如缺少稳定元素 ID；
- 提示：不影响导入，如发现新的元素文本。

#### 幂等性

重复上传同一源文件时，系统依据文件哈希提示“文件已导入”。相同唯一键的数据不得静默重复累加。

### 11.3 页面与截图管理

#### 功能

- 上传原始页面长截图；
- 上传一个或多个热力图截图；
- 填写视口宽高、设备、日期范围、页面版本；
- 支持缩放、平移、透明度切换和并排对比；
- 标注页面区块；
- 管理历史页面版本；
- 查看截图与数据筛选条件是否一致。

#### 限制

- MVP 不自动登录官网抓图；
- 动态弹窗、轮播、悬浮元素需作为独立页面状态上传；
- 截图被裁剪或比例变形时，必须提示重新上传或手动校准。

### 11.4 元素映射编辑器

#### 画布能力

- 在原始截图上显示元素边界框和点击数量；
- 通过颜色或大小表达点击份额；
- 点击元素查看数据、趋势、映射来源和置信度；
- 框选新元素、拖动边界、调整大小；
- 合并多个记录或拆分组合元素；
- 搜索元素名称、ID、文本和目标 URL；
- 筛选已映射、待确认、未映射和已失效元素；
- 撤销和重做当前编辑操作；
- 保存草稿和发布映射版本。

#### 显示要求

- 不使用颜色作为唯一信息表达，同时显示数值或标签；
- 点击量跨度较大时支持线性、对数和分位数三种色阶；
- 画布图例显示当前指标、范围和色阶；
- 标签不得遮挡关键页面内容，可折叠或仅悬停显示。

### 11.5 热力诊断视图

#### 左侧画布

- 原页面、系统生成点击覆盖层、神策截图三种图层；
- 图层可单独开关及调整透明度；
- 支持点击次数、点击份额、日变化和异常分数切换；
- 页面区块分界可见；
- 点击元素后高亮相关问题。

#### 右侧诊断面板

- 当前数据层级与质量分；
- 核心指标；
- 自动发现问题列表；
- 元素详情；
- 优化建议草稿；
- 添加备注、指派负责人、创建任务。

### 11.6 元素排行

列表字段：

- 排名；
- 元素名称和缩略位置；
- 元素类型、页面区块；
- 点击次数；
- 点击份额；
- 较对比期变化；
- 趋势迷你图；
- 映射状态；
- 诊断标签；
- 是否主 CTA。

支持搜索、筛选、排序和导出。总计行必须说明统计口径，未映射元素需单独显示。

### 11.7 趋势与时间对比

#### 趋势图

- 最多选择 10 个元素；
- 支持日、周粒度；
- 显示原始值、7 日移动均值和页面总点击；
- 支持活动节点和页面发布时间标注；
- 对缺失日使用断线，不自动补 0。

#### 时间对比

- 支持自定义基线期和对比期；
- 默认建议选择相同星期结构和相同长度；
- 展示点击次数、点击份额和排名变化；
- 若页面流量数据可用，优先展示归一化指标；
- 流量、渠道、设备或版本结构明显不同时显示可比性风险。

### 11.8 自动诊断

系统按规则生成候选问题，不直接发布。每条诊断必须包含：

- 问题标题；
- 问题类型；
- 涉及页面、区块和元素；
- 观察到的数据；
- 对比基线；
- 可能解释；
- 不确定性与替代解释；
- 影响指标；
- 严重度；
- 置信度；
- 建议动作；
- 验证方案。

详细规则见第 12 章。

### 11.9 优化建议与任务

#### 建议结构

```text
观察：发生了什么
证据：哪些数据支持这一观察
可能原因：页面语境下的候选解释
优化假设：如果做 X，预计 Y 指标发生 Z 方向变化
执行建议：具体调整内容
目标指标：期望改善的核心指标
护栏指标：不能恶化的指标
验证方式：A/B、分阶段上线或前后对比
风险：样本、埋点、流量结构和实现风险
```

#### 任务字段

- 任务标题；
- 来源诊断；
- 页面和版本；
- 负责人；
- 优先级；
- 状态：待评审、待开发、开发中、待上线、观察中、已复盘、已关闭；
- 计划上线日期；
- 基线区间和观察区间；
- 目标指标与护栏指标；
- 实际结果和结论。

### 11.10 报告中心

#### 报告内容

1. 执行摘要；
2. 数据范围、数据层级和质量声明；
3. 页面目标与主 CTA；
4. 核心指标；
5. 热力分布图和元素排行；
6. 重点问题；
7. 优化建议及优先级；
8. 验证计划；
9. 数据限制与风险；
10. 附录：指标口径、导入批次和截图信息。

#### 报告状态

- 草稿：仅作者及协作者可见；
- 待审核：增长负责人审核；
- 已发布：内容和数据快照不可直接修改，修改需创建新版本；
- 已归档：保留只读访问。

#### 导出

- MVP 支持 Markdown 和 PDF；
- 导出内容包含生成时间、作者、版本和数据快照 ID；
- 截图中隐藏敏感 URL 参数；
- 图表采用静态可阅读版本。

### 11.11 评论与审计

- 用户可对诊断、建议和任务评论；
- 记录数据导入、删除、映射修改、规则调整、报告发布和强制发布；
- 审计日志不可由普通用户删除；
- 报告中的结论必须能追溯至数据批次和规则版本。

## 12. 诊断规则与建议生成

### 12.1 诊断框架

系统先判断“数据是否足够”，再判断“观察是否显著”，最后生成“可验证假设”。诊断输出分为五类：

1. 注意力分配；
2. 核心任务表现；
3. 页面结构与位置；
4. 趋势与异常；
5. 数据与埋点质量。

### 12.2 MVP 规则清单

#### R01 主 CTA 点击份额偏低

- 前提：主 CTA 已正确标记，已记录元素覆盖相对稳定；
- 触发：主 CTA 点击份额低于页面历史 P25，或较基线下降超过设定阈值；
- 证据：主 CTA 点击次数、份额、排名和变化；
- 可能解释：视觉层级不足、文案不清楚、前置信息不足、用户被次要入口分流；
- 禁止结论：不得直接称“主 CTA 点击率低”；
- 建议验证：强化主 CTA 视觉或文案，观察主 CTA 份额；接入 UV 后以 CTA 点击 UV 率作为目标指标。

#### R02 次要入口分流明显

- 前提：主次元素由页面负责人标注；
- 触发：一个或多个次要入口合计点击份额高于主 CTA，且与页面业务目标不一致；
- 可能解释：次要入口更醒目、用户意图与页面预设不同、主流程信任不足；
- 建议验证：调整层级、合并入口或改变信息顺序，同时设置次要入口转化为护栏指标。

#### R03 点击过度分散

- 触发：Top 3 份额或 HHI 较历史基线显著下降；
- 可能解释：页面选择过多、主路径不清晰、多个 CTA 文案重复；
- 注意：内容探索型页面的分散点击可能符合预期，必须结合页面类型审核。

#### R04 点击过度集中

- 触发：Top 1 或 Top 3 份额显著高于历史分布；
- 可能解释：核心入口有效，也可能是其他重要功能不可见或埋点缺失；
- 建议：先核查埋点完整性，再决定是否属于问题。

#### R05 元素点击异常上升或下降

- 默认方法：当日值相对最近 7 个有效日移动基线的偏离超过阈值，同时绝对变化量达到最小样本要求；
- 增强方法：有足够历史数据时使用稳健 Z-score 或季节性基线；
- 必须同时检查：页面总流量、活动节奏、页面版本、埋点变化；
- 输出：异常而非好坏判断。

#### R06 元素排名大幅变化

- 触发：元素点击份额排名较可比基线变化超过 N 位，且份额变化达到阈值；
- 用途：发现热点迁移；
- 排除：新增、删除或改名元素需单独标记。

#### R07 首屏核心任务弱势

- 前提：完成首屏区域标注；
- 触发：首屏主 CTA 份额持续低于其历史基线，同时首屏次要元素更强；
- 不得推断：无曝光数据时，不能判断页面下方区域效率高低。

#### R08 重复或竞争 CTA

- 前提：人工或规则识别多个 CTA 指向同一业务目标；
- 触发：多个 CTA 文案相近但表现差异大，或位置相邻且点击分散；
- 建议验证：统一文案、明确层级或按用户阶段区分；
- 注意：页面不同位置重复 CTA 可能是合理设计，需人工审核。

#### R09 疑似无效/误触热点

- MVP 仅在点击数据包含非交互元素或坐标点击时启用；
- 触发：非预期元素存在稳定高点击；
- 建议：核查用户是否误认为可点击、交互反馈是否缺失；
- 若数据仅含按钮事件，不显示此规则。

#### R10 数据覆盖或埋点异常

- 触发：页面总点击突然归零、多个元素同时断崖下降、新页面版本出现大量未映射元素、截图热点与结构化数据明显不一致；
- 优先级：高；
- 输出：先修复数据，不生成页面设计建议。

### 12.3 阈值策略

MVP 初始阈值不写死在代码中，由管理员配置并带默认值：

- 最小分析周期：7 个有效日；
- 元素最小累计点击：30；
- 份额变化提示阈值：3 个百分点；
- 份额变化重点阈值：5 个百分点；
- 排名变化阈值：3 位；
- 异常偏离阈值：以稳健统计或业务配置为准；
- 新元素观察期：至少 3 个有效日。

当历史不足时，仅展示描述性统计，不生成“高于/低于正常水平”的判断。

### 12.4 严重度

| 等级 | 定义 | 处理要求 |
|---|---|---|
| P0 数据阻断 | 数据或映射问题导致结论不可用 | 先修复，不发布页面建议 |
| P1 高 | 涉及主 CTA 或核心业务路径，变化大且持续 | 优先进入评审 |
| P2 中 | 影响次要路径或局部区块，有明确优化空间 | 排期处理 |
| P3 低 | 弱信号、样本小或探索性发现 | 继续观察 |

### 12.5 置信度

置信度不是业务影响大小，由以下维度共同计算：

- 数据完整度；
- 样本量；
- 映射准确度；
- 变化持续时间；
- 是否有可比基线；
- 是否存在流量、版本、渠道等替代解释。

展示为高、中、低，并解释扣分原因。低置信度建议默认不进入执行清单，除非人工确认。

### 12.6 建议优先级

使用 RICE 的简化版本：

```text
Priority Score = Reach × Impact × Confidence / Effort
```

- Reach：受影响页面访问量；没有 UV 时使用页面点击规模等级替代，并明确标注代理指标；
- Impact：对核心路径的预期影响，分 0.5/1/2/3；
- Confidence：诊断置信度 0-1；
- Effort：产品、设计和研发工作量等级。

系统提供建议值，最终优先级由负责人确认。

### 12.7 生成式能力使用规范

如果后续接入大模型用于撰写建议，必须遵循：

1. 输入中包含页面目标、元素语义、诊断证据、指标口径和限制；
2. 输出严格区分观察、解释和建议；
3. 不生成数据中不存在的数字；
4. 不宣称一定提升转化或留存；
5. 每条建议引用对应诊断 ID；
6. 发布前必须由人审核；
7. 私有数据不得发送至未经公司批准的外部模型服务。

## 14. 权限、安全与部署

### 14.1 部署原则

- 与神策私有化环境匹配，优先部署在公司内网；
- 数据库、对象存储和应用日志均使用公司批准的基础设施；
- 外部网络默认不可访问原始数据与截图；
- 后续调用模型服务时需单独通过安全评审。

### 14.2 数据最小化

MVP 只处理页面、元素、日期和聚合点击数据，不要求导入明文用户 ID、手机号、Cookie 或 IP。V2 如需用户级转化和留存分析，必须使用不可逆哈希标识并进行访问隔离。

### 14.3 权限要求

- 页面级权限：按项目或页面授权；
- 操作级权限：导入、编辑、发布、导出、管理分离；
- 报告发布需要增长负责人或指定审核人权限；
- 原始文件下载默认只对分析管理员开放；
- 账号停用后保留其历史操作记录。

### 14.4 安全要求

- 传输和存储加密；
- 文件类型和大小校验；
- 防止表格公式注入；
- 截图和导出文件使用不可预测地址并校验权限；
- 日志不记录完整敏感 URL 参数和用户标识；
- 支持配置数据保留周期和删除流程；
- 高风险操作需要二次确认并写审计日志。

## 16. 异常与边界场景

| 场景 | 系统处理 |
|---|---|
| 某日无记录 | 显示“缺失”，不自动补 0 |
| 明确确认某日点击为 0 | 保存为 0，并保留确认来源 |
| 页面改版但未填写版本 | 检测到大量元素变化后要求新建版本 |
| 同名按钮出现多次 | 使用稳定 ID、目标 URL 和位置区分，不能仅按文本合并 |
| 多个子元素属于同一按钮 | 支持组合元素并保留原始记录 |
| 热力图截图和数据日期不同 | 禁止叠加，允许并排查看并显示警告 |
| 页面长截图宽度不同 | 先校准视口和缩放比例，再允许映射 |
| 元素点击突然归零 | 先触发埋点异常，不给页面优化建议 |
| 数据只覆盖部分按钮 | 所有份额指标标记“已埋点元素内” |
| 活动首日无历史基线 | 只展示描述性统计，不报趋势异常 |
| 页面总流量大幅变化 | L1 提示无法区分流量和页面因素 |
| 点击量很小但变化率很高 | 应用最小样本门槛，不触发高优先级问题 |
| 元素跳转同一目标 | 可按元素分别分析，也可聚合为业务入口 |
| 用户重复点击 | 只有 click_count 时标记为未知；有 click_uv 后计算重复点击系数 |

## 18. 验收标准

### 18.1 数据导入

1. 给定标准模板，系统能正确导入三个页面至少 30 日的数据。
2. 字段缺失、负数、非法日期和重复唯一键均得到明确反馈。
3. 同一文件重复上传不会导致数据翻倍。
4. 导入结果可追溯到源文件和操作者。

### 18.2 元素映射与画布

1. 用户可以在截图上创建、移动、缩放和删除元素框。
2. 元素数据与画布位置双向联动。
3. 发布前主 CTA 映射覆盖率为 100%。
4. 系统能显示未映射点击量占比。
5. 原图、系统覆盖层和神策截图可独立开关。

### 18.3 指标与诊断

1. 点击次数、点击份额、Top 3 份额和趋势计算与人工核算一致。
2. 在只有点击次数时，界面与导出报告中不出现未经定义的 CTR、转化率或留存率。
3. 每条正式诊断均含证据、口径、置信度和替代解释。
4. 数据质量不达标时，系统阻止或明确警告报告发布。
5. 埋点异常优先于页面优化建议显示。

### 18.4 报告与闭环

1. 报告可保存草稿、审核、发布和版本化。
2. 导出内容与在线报告指标一致。
3. 任一建议可创建优化任务，并保存目标及护栏指标。
4. 改版后可以选择对比区间并记录复盘结论。
5. 已发布报告可追溯至数据快照、映射版本和规则版本。

### 18.5 权限与安全

1. 无页面权限的用户无法查看截图、数据或报告。
2. 普通用户无法发布报告或下载原始文件。
3. 所有高风险操作均产生审计记录。
4. CSV/XLSX 导出不存在可执行公式注入风险。

## 20. 风险与应对

| 风险 | 影响 | 应对方案 |
|---|---|---|
| 只有点击数、缺少 PV/UV | 无法判断点击效率 | 明确 L1 数据层级，推动补充 PV/UV |

## 22. 建议的数据补充优先级

为了真正回答“如何提高点击、转化和留存”，建议按以下顺序补齐数据：

1. **页面 PV/UV**：先把点击规模转化为可比较的页面效率指标；
2. **元素 click_uv**：识别重复点击，获得主 CTA 点击用户率；
3. **元素曝光 UV**：区分“用户没看到”和“看到了但没点击”；
4. **目标转化事件**：验证点击是否带来实际业务结果；
5. **渠道、设备、新老用户**：解释流量结构差异；
6. **留存事件和匿名用户标识**：建立行为到留存的分析链路；
7. **实验分组信息**：将相关性观察升级为因果验证。

这是本产品能否从“热力观察工具”升级为“增长决策系统”的关键路径。

## 附录 A：示例诊断

### 示例：主 CTA 点击份额连续下降

**观察**  
2026-07-14 至 2026-07-20，“立即领取”按钮获得 2,840 次点击，占已埋点元素点击的 31.2%；上一个可比 7 日为 38.7%，下降 7.5 个百分点。该按钮的页面内排名由第 1 降至第 2。

**数据声明**  
当前为 L1 点击观察数据。未提供页面 UV、元素曝光和点击 UV，因此不能判断真实 CTR 是否下降，也不能排除流量结构或重复点击变化。

**可能解释**

- 新增的“查看活动规则”入口分流了点击；
- 主 CTA 文案与当前活动利益点匹配不足；
- 页面版本或埋点发生变化；
- 流量来源变化导致用户意图不同。

**优化假设**  
若将核心利益点加入主 CTA 文案并降低活动规则入口的视觉优先级，主 CTA 在已记录点击中的份额可能回升。

**验证方案**

- 优先方案：A/B 测试；
- 目标指标：主 CTA 点击 UV / 页面 UV；
- 护栏指标：规则入口点击 UV、页面转化率、投诉或退出指标；
- 当前数据下的临时观察指标：主 CTA 点击份额；
- 最小观察周期：覆盖完整星期结构，样本量另行估算。

**置信度**  
中。变化幅度和持续时间满足规则，但缺少 UV、曝光和渠道数据。

## 附录 C：名词表

| 名词 | 定义 |
|---|---|
| 点击次数 | Web 点击事件发生次数，可能包含同一用户重复点击 |
| 点击 UV | 至少点击一次的去重用户数 |
| 页面 UV | 所选范围内访问页面的去重用户数 |
| 元素曝光 UV | 实际看到该元素的去重用户数，需定义曝光阈值 |
| 点击份额 | 某元素点击次数占页面已纳入元素总点击次数的比例 |
| CTR | 点击用户数/曝光用户数，或按明确业务口径定义；不能用点击次数直接替代 |
| 主 CTA | 页面为实现核心业务目标而设置的主要行动入口 |
| 护栏指标 | 优化目标提升时不能显著恶化的指标 |
| 数据层级 | 根据分母、转化和留存数据是否齐全划分的分析能力等级 |
| 置信度 | 对诊断证据可靠性的评级，不代表预期业务影响大小 |
| 页面版本 | 一次结构或视觉改版后形成的可独立比较页面状态 |
