## 1. 执行摘要

本次分析基于三个页面的 Area 点击次数和 Clarity 来源 CTR：

1. **AI Agent 页的核心体验路径最清晰。** “模型广场”“Agent 体验”“立即体验”位列前三，前三元素贡献 49.9% 的 Area 点击事件，说明用户对模型浏览和在线体验有明确需求。下一步应优先把“体验 - 注册/登录 - 创建 API Key”的链路串起来，并用转化事件验证是否存在中间流失。
2. **AI 订阅页的主要兴趣集中在模型发现和套餐周期。** “展开全部模型”单项 963 次点击、来源 CTR 18.42%，明显高于页面其他元素；四个模型卡合计 746 次点击。用户可能希望比较更多模型，但当前模型信息存在折叠或入口隐藏。注册/登录入口只有 95 次点击，页面兴趣没有充分转化为明确的注册行为。
3. **春季活动页的点击注意力最分散，且工具型入口抢占注意力。** “控制台” 838 次点击、来源 CTR 4.72%，高于单个活动购买入口；43 行同名“立即购买”合计 409 次点击，但无法定位到具体活动模块。该页面首先需要治理埋点和 CTA 层级，再讨论视觉或文案优化。
4. **不能将本次 Area 点击直接表述为真实 CTR、转化率或留存率。** CSV 中的“点击率 (CTR)”是 Clarity 导出的来源字段；本报告不重新用点击次数除以页面查看次数计算 CTR。页面查看次数只能用于规模和粗略交互强度参考，不能替代用户去重、元素曝光或转化分母。

### 建议优先级

| 优先级 | 页面 | 优先动作 | 原因 |

## 4. 页面一：AI 订阅页

页面 URL：`https://www.qiniu.com/ai/plan`  
页面查看次数：3,421  
Area 点击事件：3,443  
数据文件：`Clarity_注册_Area_电脑_07-24-2026 17 21.csv`

### 4.1 主要点击元素

| 排名 | 元素 | 点击次数 | 来源 CTR | 点击事件份额* |
|---:|---|---:|---:|---:|
| 1 | 展开全部模型 | 963 | 18.42% | 28.0% |
| 2 | DeepSeek 模型卡 | 327 | 6.25% | 9.5% |
| 3 | AI 大模型（导航） | 293 | 5.60% | 8.5% |
| 4 | 包月 | 284 | 5.43% | 8.2% |
| 5 | Moonshot AI 模型卡 | 190 | 3.63% | 5.5% |
| 6 | 包年 | 177 | 3.39% | 5.1% |
| 7 | 智谱 AI 模型卡 | 169 | 3.23% | 4.9% |
| 8 | 包季 | 160 | 3.06% | 4.6% |
| 9 | API Key 统一接入多个模型系列 | 125 | 2.39% | 3.6% |
| 10 | 登录免费注册 | 95 | 1.82% | 2.8% |

\* 点击事件份额 = 单行点击次数 / 该文件所有 Area 点击次数，仅用于观察页面内部注意力，不是用户点击率。

### 4.2 关键发现

**发现 A：模型发现是第一需求。**  
“展开全部模型”单项 963 次，四个可识别模型卡（DeepSeek、Moonshot AI、智谱 AI、MiniMax）合计 746 次；模型浏览相关点击至少 1,709 次，占 Area 点击事件的 49.6%。这说明用户很可能先比较模型覆盖、能力或价格，再决定是否进入订阅。

**发现 B：套餐周期存在明确选择行为。**  
包月、包季、包年合计 621 次，占 18.0%。用户不只是浏览内容，也在比较订阅周期。包月 284 次高于包年 177 次和包季 160 次，但不能据此判断最终购买偏好，因为这里是点击事件，不是订单或支付。

**发现 C：兴趣到注册之间存在可疑断层。**  
“登录免费注册”只有 95 次，而“展开全部模型”是其 10.1 倍。可能原因包括：

- 用户仍处于比较阶段，尚未准备注册；
- 注册入口与模型/套餐信息距离较远；
- CTA 文案没有承接“模型选择”这一高兴趣行为；
- 注册按钮埋点覆盖不完整或存在其他注册入口。

### 4.3 优化建议

1. **将“展开全部模型”升级为更明确的模型选择体验。** 展开后直接展示模型能力、价格或适用场景，并在列表末端固定一个“选好模型，开始使用”的 CTA。
2. **把模型卡点击与订阅周期选择关联。** 记录 `model_id`、`plan_cycle`、`click_to_register`，区分用户是在看模型、看套餐，还是已经进入购买意图。
3. **减少“浏览后找不到下一步”的风险。** 在模型展开区、套餐比较区增加就近的注册/试用 CTA，并使用统一的 `start_trial` 或 `register_from_plan` 事件。
4. **核查“登录免费注册”是否是唯一注册入口。** 如果页面还有“立即开始”“免费试用”等入口，应使用统一业务入口 ID，避免注册行为被拆散。

### 4.4 验证指标

- 主指标：模型卡或模型展开后的注册 UV / 页面 UV；
- 次指标：模型选择 → 注册开始 → 注册完成 → API Key 创建；
- 护栏指标：套餐详情查看率、退出率、客服咨询量；
- 当前只能观察：模型展开点击份额、模型卡点击份额、注册入口点击份额。

|---:|---|---:|---:|---:|

### 5.2 关键发现

**发现 A：控制台是最高点击入口，页面目标可能被工具型导航分流。**  
“控制台” 838 次，占该文件 Area 点击事件的 19.3%，来源 CTR 4.72%。单行“立即购买”只有 214 次、1.21% CTR；即使把 43 行同名“立即购买”合计后得到 409 次，也仍低于控制台。若页面目标是活动领取或购买，应先确认控制台入口是否属于页面预期主路径；如果不是，它就是重要的分流信号。

**发现 B：活动内容有兴趣，但点击分布很散。**  
云服务器、AI 大模型、Token Plan、CDN 专区、存储专区、新客专区等多个主题都有点击，Top 3 点击份额仅 31.8%，Top 5 仅 41.5%。用户可能在“找适合自己的优惠”，但页面缺少一个足够清晰的主路径。

**发现 C：购买 CTA 无法归因。**  
文件中有 43 行名称完全相同的“立即购买”，合计 409 次点击（占 Area 点击事件 9.4%），但无法知道哪些点击来自 AI 订阅、云服务器、CDN、存储或其他活动卡。当前数据不能回答“哪个活动的购买按钮最有效”。

**发现 D：有较多 0 点击区域。**  
111 行 Area 中有 28 行点击为 0，占 25.2%。这可能是页面真实低关注，也可能是元素不可见、区域采集失败、模块已下线或文本被拆分。发布页面优化结论前，应先抽查这些区域。

### 5.3 优化建议

1. **先做埋点治理，再做 UI 优化。** 每个活动模块使用唯一 `module_id`，CTA 使用 `module_id + cta_type`，例如 `spring_ai_subscription_buy`，避免使用“立即购买”作为唯一名称。
2. **把控制台从活动主路径中单独分组。** 报告中将导航/工具入口与活动内容入口分开计算，避免控制台点击量抬高页面总量并掩盖活动 CTA 表现。
3. **建立“活动主题 → 详情 → 领取/购买”的统一路径。** 每个活动卡的主 CTA 文案和事件名保持一致，并记录卡片曝光、详情查看、优惠券领取、购买开始、购买完成。
4. **对 0 点击模块做页面级抽样检查。** 重点排查折叠区、懒加载区、弹窗遮挡、设备适配和埋点路径变化，不能直接将 0 点击视为用户不感兴趣。
5. **减少同一页面上多个“立即购买”的视觉竞争。** 活动数量较多时，用“查看优惠”承接浏览，用“立即购买”只保留给已经明确选择的模块。

### 5.4 验证指标

- 主指标：按 `module_id` 聚合的购买开始 UV / 模块曝光 UV；
- 次指标：优惠券领取率、详情查看率、购买完成率；
- 护栏指标：控制台点击率、页面退出率、其他模块点击份额；
- 当前只能观察：各活动模块点击次数和来源 CTR，不能判断购买转化。

### 6.1 主要点击元素

| 排名 | 元素 | 点击次数 | 来源 CTR | 点击事件份额 |
|---:|---|---:|---:|---:|
| 1 | 模型广场 | 2,135 | 14.75% | 24.6% |
| 2 | Agent 体验 | 1,290 | 8.91% | 14.8% |
| 3 | 立即体验 | 909 | 6.28% | 10.5% |
| 4 | AI 大模型 | 874 | 6.04% | 10.1% |
| 5 | 控制台 · API Key | 710 | 4.91% | 8.2% |
| 6 | 去购买 | 343 | 2.37% | 3.9% |
| 7 | 立即注册/登录 | 238 | 1.64% | 2.7% |
| 8 | 免费注册 | 236 | 1.63% | 2.7% |
| 9 | 登录 | 220 | 1.52% | 2.5% |
| 10 | 一站式接入大模型能力内容区 | 222 | 1.53% | 2.6% |

### 6.2 关键发现

**发现 A：用户核心兴趣集中在“看模型”和“马上体验”。**  
模型广场、Agent 体验、立即体验三个元素合计 4,334 次，占 Area 点击事件 49.9%，且来源 CTR 合计 29.94%。这比传统内容区和 FAQ 的点击更强，说明用户对产品可操作体验的兴趣超过纯信息阅读。

**发现 B：API Key 是重要的中后段动作。**  
“控制台 · API Key” 710 次，来源 CTR 4.91%，高于“去购买”343 次。这可能说明一部分用户目标不是先购买，而是先完成接入或验证 API 能力。页面应把体验、注册、创建 Key 和购买区分成不同用户路径。

**发现 C：注册入口存在分散。**  
“立即注册/登录”“免费注册”“登录”合计 694 次，分别分布在不同入口。单看点击量不能判断哪个入口带来的注册质量更高，但入口分散会增加漏斗分析和页面优化难度。

### 6.3 优化建议

1. **将“立即体验”从单一按钮升级为可追踪的体验漏斗起点。** 记录 `experience_start`、注册开始、注册完成、首个模型调用、API Key 创建和首次成功请求。
2. **把模型广场和 Agent 体验做成两条明确的分流路径。** 对“想选模型”的用户引导到模型广场，对“想直接试用”的用户引导到 Agent 体验，避免两个强入口互相竞争。
3. **统一注册/登录入口的业务事件。** 视觉上可以保留不同位置，但事件统一为 `auth_entry`，另加 `entry_position`，从而比较首屏、体验区、底部 CTA 的真实效果。
4. **强化 API Key 的承接文案。** 如果 API Key 是有效激活动作，应在体验后明确提示“创建 API Key 开始接入”，并用激活率而不是点击量作为后续判断依据。

### 6.4 验证指标

- 主指标：体验开始 → 注册完成 → 首次模型调用 → API Key 创建的漏斗转化率；
- 次指标：模型广场点击后的模型详情查看和体验启动率；
- 护栏指标：页面退出率、客服咨询、购买入口点击；
- 当前只能观察：体验入口点击份额、注册入口点击量、API Key 入口点击量。

## 7. 三页统一优化方案

### 7.1 埋点规范

建议最少补充以下字段：

| 字段 | 用途 |
|---|---|
| `page_id` | 区分页面 |
| `page_version` | 区分改版前后 |
| `module_id` | 区分活动/内容模块 |
| `element_id` | 区分真实按钮，不使用可变文案作为唯一标识 |
| `element_type` | nav、card、cta、faq、form 等 |
| `element_position` | header、hero、middle、footer 等 |
| `device_type` | desktop、mobile、tablet |
| `impression_event` | 记录元素是否曝光 |
| `click_event` | 记录点击 |
| `click_uv` | 去重点击用户 |
| `conversion_event` | 注册、购买、Key 创建、首次调用 |

### 7.2 建议建立统一漏斗

```text
页面曝光
  → 核心内容/产品入口点击
  → 体验或详情开始
  → 注册/登录开始
  → 注册/登录完成
  → 激活动作（创建 API Key / 首次调用 / 购买完成）
  → 业务定义的留存事件
```

三个页面可以共享漏斗框架，但核心动作不同：

| 页面 | 核心动作 | 激活动作 |
|---|---|---|
| AI 订阅页 | 模型选择、套餐查看、开始订阅 | 注册完成、API Key 创建、订阅完成 |
| 春季活动页 | 活动详情、优惠券领取、购买开始 | 购买完成或有效领取 |
| AI Agent 页 | 模型广场、Agent 体验、立即体验 | 首次成功调用、API Key 创建 |

## 8. 最终结论

如果现在只能选择一个页面优先优化，建议选择 **AI Agent 页**：它的核心点击集中在产品体验相关入口，用户意图最明确，最容易通过补齐注册、激活和留存事件快速形成增长验证闭环。

如果现在只能选择一个数据问题优先修复，建议选择 **春季活动页的元素埋点唯一性**：43 个“立即购买”无法归因，任何关于“哪个活动购买按钮表现好”的判断都不可靠。

如果现在只能选择一个页面体验问题优先验证，建议选择 **AI 订阅页的“模型浏览 → 注册/订阅”承接**：模型探索需求明显，但注册入口点击弱，存在兴趣没有被承接的可能。

### 推荐实施顺序

1. 第 1 周：完成春季活动页 P0 埋点治理，同时为三个页面补齐页面 UV、元素曝光 UV、点击 UV 和结果事件。
2. 第 2 周：优先上线 AI Agent 页双路径首屏与体验后激活引导实验，因为该页用户意图最集中、验证速度最快。
