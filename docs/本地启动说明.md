# HeatScope 本地启动说明

当前唯一前端入口是 `apps/web` 下的 Next.js 工作台。

## 安装

```bash
npm install
npm --prefix apps/web install
```

## 启动开发环境

```bash
npm run dev
```

默认地址为 `http://127.0.0.1:3000`。模型配置保存在当前浏览器工作区，`.env.local` 与 API Key 不得提交到仓库。

## 构建与启动生产版本

```bash
npm run build
npm run start
```

## Vercel 部署

```bash
npm run deploy
```

该命令从 `apps/web` 部署正式 Next.js 应用。
